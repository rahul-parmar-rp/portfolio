# Night Sight Android App

## Overview

The Night Sight app enhances the visibility and usability of mobile devices in low-light conditions, allowing users to comfortably read and interact with their screens without straining their eyes.

## Features

- **Adaptive Brightness Adjustment**: Automatically adjusts the screen brightness based on ambient light conditions.
- **Color Filter Options**: Provides customizable color filters to reduce blue light and improve eye comfort during night-time usage.
- **Night Mode**: A dedicated night mode that changes the interface to softer colors and lower brightness levels.
- **Screen Dimming**: Allows users to dim the screen further than the default settings for comfortable viewing in dark environments.
- **Scheduled Activation**: Users can set a schedule for when the app activates night mode automatically.
- **Reading Mode**: Offers a specific mode optimized for reading e-books or articles, with adjustable background color and text size.

## Use Cases

- Ideal for users who read or use their phones at night without disturbing others or straining their eyes.
- Useful for individuals who work late hours and need to reduce eye fatigue.
- Great for bedtime reading or browsing without the harsh glare of a bright screen.

## Additional Notes

- Ensure compliance with accessibility standards to improve usability for all users.
- Gather user feedback to refine color filter options and brightness levels for better customization.
