# LightsOff

## Overview

Proximity Sensor Based App which enables or disables the screen based on the Proximity Sensor of Android.

## Features

- Automatically turn off the screen when the user is not in front of the device.
- Turn on the screen when the user approaches the device.
- Customizable sensitivity settings for the proximity sensor.
- Option to disable the app during specific situations (e.g., when using certain apps).

## Use Cases

- Save battery life by preventing the screen from being on unnecessarily.
- Enhance user experience by providing seamless screen management.
- Ideal for users who frequently check their devices in various scenarios (e.g., cooking, exercising).

## Additional Notes

- Ensure compliance with privacy policies regarding sensor usage.
- User feedback on sensitivity settings can improve usability.
