# IPO Application Planner — Interactive

Play with sample people, accounts and IPOs below. Everything runs in your
browser and is saved to `localStorage` (nothing is sent anywhere).

**How to use**

1. Open the **Optimizer** tab.
2. Set a budget (use each account's funds, or a single total).
3. Pick the **accounts** and the **IPOs / quotas** to consider.
4. Click **Calculate optimal plans** and choose one with **Use this plan**.
5. Review results under **Applications**. Edit the data in **People & Accounts**
   and **IPOs**.

:::tip
Use **Reset sample** to reload the demo data, or **Clear** to start empty.
:::
