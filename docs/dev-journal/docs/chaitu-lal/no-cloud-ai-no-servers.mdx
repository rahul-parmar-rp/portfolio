# No Cloud AI, No Servers

## Overview

This document outlines a project that utilizes in-browser AI models for various applications without relying on cloud APIs or servers. The aim is to create a fully offline solution that can run on GitHub Pages, ensuring privacy and minimizing server costs. 

## Key Features

- **In-Browser AI Models**: The project leverages lightweight AI models that can run entirely within the browser using technologies like WebGPU and WebAssembly.
- **Static Site Deployment**: The solution is designed to be hosted on GitHub Pages, providing an easy and cost-effective way to share the application.
- **Flexible Applications**: Users can interact with the AI models for various tasks, such as text generation, summarization, and more, all while maintaining data privacy.

## Technical Stack

- **Transformers.js**: A library to run Hugging Face models directly in the browser.
- **WebGPU**: Utilized for accelerating AI models using the user's GPU to improve performance.
- **WebAssembly**: Runs optimized components of the models for efficiency.

## Example: local LLM in a React page

You can run a local LLM directly in the browser (no cloud, no API server) using either Transformers.js or llama.cpp compiled to WebAssembly/WebGPU.

Below is a simple React page using Transformers.js that runs a small model fully in-browser.

### Option 1: React local LLM

1. Install the dependency

```bash
npm install @huggingface/transformers
```

2. Create a React component

```jsx
import { useState } from "react";
import { pipeline } from "@huggingface/transformers";

export default function App() {
  const [input, setInput] = useState("");
  const [output, setOutput] = useState("");
  const [loading, setLoading] = useState(false);

  let generator = null;

  async function loadModel() {
    if (!generator) {
      generator = await pipeline("text-generation", "Xenova/distilgpt2");
    }
    return generator;
  }

  async function runModel() {
    setLoading(true);
    setOutput("");

    const pipe = await loadModel();
    const result = await pipe(input, {
      max_new_tokens: 80,
      temperature: 0.7,
      top_p: 0.9,
    });

    setOutput(result[0].generated_text);
    setLoading(false);
  }

  return (
    <div style={{ padding: 20, fontFamily: "sans-serif" }}>
      <h2>Local LLM (Browser Only)</h2>

      <textarea
        rows={5}
        cols={60}
        placeholder="Type something..."
        value={input}
        onChange={(e) => setInput(e.target.value)}
      />

      <br />

      <button onClick={runModel} disabled={loading}>
        {loading ? "Running..." : "Generate"}
      </button>

      <h3>Output:</h3>
      <pre>{output}</pre>
    </div>
  );
}
```

3. Run the React app

```bash
npm run dev
```

### How this works

- Model downloads once in the browser with no backend required.
- It runs using WebAssembly or WebGPU depending on the device.
- Everything stays local.

### Option 2: llama.cpp in the browser

If you want real LLaMA models, use llama.cpp compiled to WebAssembly/WebGPU or projects like llama-web and web-llm.

### Reality check

- Small models are fast but weaker.
- Big models are slow unless GPU/WebGPU is available.
- The first load can download a large model payload.
